## Approved journey

1. Open League comparison → Category strategy. Historical overview retains the
   entry to existing manager-pattern and league-pressure analysis.
2. Confirm the returning 12 and select recent three or five seasons. The cohort
   review can include the former manager to inspect the original 13-team room.
3. Compare all categories: top/middle/bottom normalized gaps share one bar scale;
   recent personal ranks provide context. Select a category.
4. Inspect its native standings curve and choose a requested point gain. The
   selected minimum counting-stat step appears on the curve. Historical rank-4/6
   thresholds show median and range separately from the selected season.
5. Check the category's equal-game rank and an independent extra-game replay.
   The latter shows total score plus category contributions. The checks do not
   represent verified available starts or combine into a roster recommendation.

The mock also exposes loading, missing manager links, missing games and retryable
error states. Missing links exclude whole seasons rather than shrinking the
cohort. Missing personal GP preserves raw standings and withholds affected games
diagnostics. Ratios retain percentage units; ratio gaps use percentage points
and have no invented integer gain ladder. Desktop and mobile layouts were
visually checked; the category comparison table scrolls within its card on mobile.

## Mapping to the existing backend

| UI | Existing result |
| --- | --- |
| Scope and filters | Explicit seasons, reviewed cohort IDs, target manager ID, extra-game count |
| Original versus cohort score | `original_standings`, `cohort_standings` |
| Three-zone comparison | `summaries[].zones` for the chosen basis |
| Recent personal ranks | Selected team's per-season category standings |
| Native curve and selected target | Category geometry tiers and `integer_gains` |
| Historical thresholds | `summaries[].thresholds` with counts and excluded seasons |
| Equal-game check | `equal_game_standings` and `per_team_game` category rows |
| Extra-game replay | `game_replay.standings`, compared with cohort standings |
| Evidence and unavailable states | Observation IDs, assignment revisions and exclusions |

The approved implementation uses a typed Angular read service to call
`GET /api/archive/cohort-study` and feed a bounded component under the existing
League comparison page. Keep scoring, thresholds and scenario calculations in
Python. SVG coordinates, formatting, selected-category state and presentation
comparisons belong in Angular. Existing auction and manager-pattern reports
remain their current sources. No new analytical model is needed for this mock.

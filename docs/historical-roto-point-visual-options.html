Shared unit: league-spread share per point tier. gap between adjacent totals ÷ category P90–P10 spread. Each adjacent rank differs by one ROTO point in this synthetic, untied example. Matching a neighboring total creates a tie and changes the score by half a point; passing it changes the score by a full point.

Evidence and calculation notes

All six categories use invented 2026 higher-is-better counting totals for 12 invented teams. P90–P10 uses inclusive linear interpolation. Values are singleton tiers; a real view must retain exact ties, lower-is-better orientation, ratio makes and attempts, unavailable boundaries, manager-link eligibility, source observation and exclusions.

The shared unit describes the final league distribution. It is not a player production rate, fantasy value, or exchange rate between categories.

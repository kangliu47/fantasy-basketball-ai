What the design already gets right

Dependency direction

Ports belong to use cases.

Application code depends on protocols and domain objects. Infrastructure implements those contracts; bootstrap binds them. A fresh static import check found no forbidden inward-layer imports.

Evidence boundaries

Facts and assumptions differ.

Imported observations carry coverage and timestamps. Manager identity is reviewed. Plans retain copied rules as a provisional reference and store the user’s own targets.

Local interaction

The UI drives routine use.

A launcher, browser sign-in and typed Angular requests avoid routine terminal work. Preparation reads saved evidence through application ports without needing provider credentials.

Review scope: source, public contracts, storage semantics, existing tests and documented delivery evidence. This artifact makes no product changes, reads no private workspace data, and is not a load test or independent validation of ESPN’s current API.

    04 / Data & consistency

    Different records,
    different guarantees.

    “Saved in DuckDB” does not mean every record is immutable or that an entire research view is read atomically. These distinctions matter when turning exploration into a reproducible draft decision.

    Who owns concurrency?

    BoundaryCurrent mechanismWhat it does not provide
    Integration operationsWorkspaceService and HistoryService each have asyncio locks and task state. HTTP routes check the other service’s idle status.An atomic cross-service admission reservation; coordination across processes.
    Database accessOne bootstrap-owned repository RLock serializes short-lived connections for all three adapters.A distributed lock, or a transaction spanning multiple repository calls.
    Plan editsExpected revision check and replacement under the shared lock.History of earlier plan documents; conflict-aware merging of dirty form fields.
    Research viewsLatest successful observation per dataset, then separate identity reads and calculations.A pinned cross-dataset evidence manifest or point-in-time aggregate view.

    Three forms of time

    Retrieved time says when the adapter read a dataset. Effective time says when it applied, if known. Planning season says which future decisions the user is preparing for.

    Do not substitute one for another. Final rosters do not establish continuous player ownership; late-season player totals do not reconstruct earlier decision inputs.

    Three forms of identity

    Provider player IDs support cross-year player research. Season-scoped team IDs identify one year’s teams. Local manager IDs connect reviewed assignments across years.

    Internal ownership references only suggest continuity. They do not establish a manager’s full-season responsibility and are filtered out of public DTOs.
